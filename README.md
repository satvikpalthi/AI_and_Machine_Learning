## 🚀 Projects

### 1. Face Recognition Attendance System

An automated attendance management application that uses facial recognition to identify registered individuals and record their attendance.

**Key Features:**
- Face data collection using a webcam.
- Face recognition using OpenCV.
- Automatic attendance recording.
- Attendance storage in CSV format.
- Reduced manual attendance work.

**Technologies:** Python, OpenCV, NumPy, CSV.

## ⚙️ Installation and Setup

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Install the required libraries.

```bash
pip install -r requirements.txt
```

5. Run the required Python file.

```bash
python capture_faces.py
```

*Note: Follow the individual project's README for its complete setup and execution instructions.*
